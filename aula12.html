Sobre o Guia de Prática

Dica: Use line-height: 1.6 e margin-bottom para melhorar a leitura de blocos de texto longos.

  • Seletores CSS: Pratique selecionar por tag (ex: p), classe (ex: .card) e ID (ex: #inicio).
  • Pseudo-classes: Experimente aplicar estilos interativos usando :hover e :focus nos links e botões.
  • Responsividade: Crie uma media query @media (max-width: 768px) para adaptar seu layout para smartphones.
